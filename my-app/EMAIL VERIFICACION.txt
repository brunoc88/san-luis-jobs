Sobre el flujo de confirmación

Vas MUY bien encaminado.

La arquitectura correcta sería:

Flujo ideal
POST /api/user

Crear token de confirmación
Enviar mail
Responder OK
Luego
GET /api/user/confirm?token=xxx
Buscar token
Verificar expiración
Activar usuario
Borrar token
Responder éxito
IMPORTANTE

NO uses JWT para confirmación de email al principio.

Muchos tutoriales lo hacen y termina siendo incómodo.

Mejor:

Tabla separada
model EmailVerificationToken {
  id        Int      @id @default(autoincrement())
  token     String   @unique
  userId    Int
  expiresAt DateTime

  user User @relation(fields: [userId], references: [id], onDelete: Cascade)
}

Mucho más controlable.
